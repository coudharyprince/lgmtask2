# API-Driven User Directory Demo

A small front-end exercise that retrieves sample user records from the ReqRes API and displays profile images, names, and email addresses in a browser page.

## Features

- Fetches sample user records from an external API
- Displays user avatars
- Displays first and last names
- Displays email addresses
- Uses a button to trigger the request

## Built with

- HTML
- CSS
- JavaScript
- Fetch API
- [ReqRes](https://reqres.in/) sample API

## Run locally

1. Clone this repository:
   ```bash
   git clone https://github.com/coudharyprince/lgmtask2.git
   ```
2. Open `LGM/index.html` in a browser.
3. Select **GET USER** to request and display the sample records.

The page requires an internet connection and a compatible response from the external API. API availability and authentication requirements may change.

## Project notes

This is a front-end API-integration exercise. It is not a production user-management system and should not be used to display real personal data.
